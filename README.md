# Заметки

Приложение для Android на Python (Kivy): заметки (текст и чек-листы), календарь и расписание уроков на 6 дней (Пн–Сб). Работает офлайн, данные хранятся на устройстве.

## Возможности

- Заметки: текст и списки с галочками, папки, закрепление, цвет фона, размер шрифта, дата, поиск, 8 вариантов сортировки
- Календарь: месяц, отметки дней с заметками, расписание и заметки выбранного дня
- Расписание: вкладки Пн–Сб, время начала и конца, кабинет, преподаватель, цвет, подсветка текущего урока
- Светлая и тёмная тема, резервная копия через буфер обмена

## Сборка APK

**Windows** — сначала распакуйте архив (запуск из самого архива не работает), затем двойной щелчок по `build.bat`. Нужен WSL с Ubuntu (если его нет, скрипт подскажет команду установки). Окно не закрывается само: в конце показывается результат или ошибка.

**Linux / WSL** — `./build.sh`

Первый запуск занимает 20–40 минут (скачиваются Android SDK и NDK), следующие — несколько минут. Готовый файл появится в `bin/zametki-1.0.0-arm64-v8a_armeabi-v7a-debug.apk`; скопируйте его на телефон и установите (разрешите установку из неизвестных источников).

**Если WSL ставить не хочется** — загрузите папку в репозиторий GitHub: вкладка Actions → `build-apk` → Run workflow. APK скачивается из Artifacts.

## Для Google Play

`./build.sh aab` (или `build.bat aab`) создаёт ключ подписи `release.keystore` и собирает `.aab`. Ключ и пароль (`release.keystore.pass`) сохраните: потерять их нельзя, обновления приложения подписываются тем же ключом.

Перед публикацией проверьте актуальные требования Google к целевой версии Android (`android.api` в `buildozer.spec`). Сейчас стоит 33 (проверенное сочетание с Kivy 2.3.0 и python-for-android 2024.01.21); если Play потребует более новую, поднимите значение и проверьте отступы под системные панели на Android 15+.

## Запуск на компьютере

    pip install kivy==2.3.0
    python main.py

## Тесты

    python -m unittest discover -s tests

## Структура

- `main.py` — приложение, тема, навигация
- `core/` — хранилище, даты, цвета (без зависимости от Kivy)
- `ui/` — экраны, виджеты, шторки, разметка `.kv`
- `assets/` — иконки (создаются `tools/make_assets.py`)
